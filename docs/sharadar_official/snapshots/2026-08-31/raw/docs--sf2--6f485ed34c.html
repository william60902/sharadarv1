Insiders

(insiders)

Samples

Insider holdings & transactions as reported to the SEC via forms 3, 4 and 5. Normalised officer titles (ie CEO) to easily identify executive by position. Normalised security titles (ie ClA or ClB) to easily segment these. Current count of 16,000 tickers and 200,000 insiders.

Interaction

The table is queried via the following endpoint:

https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&ticker=AAPL

The queries are authenticated and filtered using query parameters. A query parameter specifies a particular option or filter for the data to be returned. Examples of query parameter include the data format to be returned (format), the table columns to return (fields) or a filter to be applied (tablename). These are appended to the endpoint above, following a ?. The most important of these is your API key (api_key) which is used to authenticate you. Without a valid API key, results will not be returned.

The insiders table supports the following query parameters:

ParameterDescriptionDefaultExamples
formatThe format of the results to be returned.csvformat=json
yearsTriggers a bulk download of the full table as a compressed CSV. Values: 5, 10, or full. The API redirects to a time-limited download URL.years=5

Examples

Return all insider data for a specified ticker:

https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&format=csv&ticker=AAPL

Return insider data for a specified owner:

https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&format=csv&ownername=COOK TIMOTHY D

Return insider data for all non-derivative transactions exceeding $100,000 between specified dates for a specified owner and ticker:

https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&format=csv&ticker=AAPL&ownername=COOK TIMOTHY D&from=2021-01-01&to=2022-12-31&securityadcode=N,NA,ND&transactionvalue.gte=100000

Google Sheets Example

In Google Sheets, retrieve insider transactions for a single ticker (AAPL) with IMPORTDATA. You can change the query parameters (ticker, dates, fields, filters, and so on) in the same way as the Examples in the preceding section. Paste this formula into a cell (A1):

=IMPORTDATA("https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&format=csv&ticker=AAPL")

Bulk Download

Download the [insiders] table as a compressed CSV by setting years to 5, 10, or full. The API responds with a redirect to a time-limited download URL:

https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&years=5

https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&years=full

Example using curl (follow redirects and write the file):

curl -L -o insiders.csv.zip "https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&years=full"

Check the bulk file status (name, size, last modified) without downloading:

https://api.sharadar.com/v1.0/data/insiders?api_key=test-api-key&status=True

Example response:

{ "table": "insiders", "name": "insiders.csv.zip", "size": 293525266, "sizeLabel": "279.9 MB", "modified": "2026-07-16T01:20:20.312000+00:00" }
